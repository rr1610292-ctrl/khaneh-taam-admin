پنل مستقل مدیریت خانهٔ طعم

1) فایل admin.html را باز کنید.
2) آیتم‌ها را اضافه/ویرایش/حذف کنید.
3) «دانلود فایل منو» خروجی khaneh-taam-menu.json را می‌دهد.
4) این فایل JSON به‌تنهایی به سایت آنلاین وصل نیست. برای نمایش تغییرات باید داده‌های آن در فایل app.js سایت جایگزین شوند و دوباره روی GitHub Pages منتشر شوند.
5) این ابزار احراز هویت ندارد؛ آن را روی سایت عمومی به عنوان پنل امن قرار ندهید و فایل را فقط در اختیار مدیر بگذارید.

در فرم افزودن/ویرایش، می‌توان تصویر را از حافظهٔ دستگاه انتخاب کرد (تا ۴ مگابایت). تصویر در خروجی JSON به صورت دادهٔ داخلی ذخیره می‌شود و ممکن است حجم فایل خروجی را زیاد کند؛ برای تعداد زیاد عکس، استفاده از پوشه images و مسیرهای نسبی توصیه می‌شود.
