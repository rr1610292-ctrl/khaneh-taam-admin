خانهٔ طعم / پنل مدیریت

مدیریت مستقل آیتم‌ها و آماده‌سازی خروجی برای انتشار

نکتهٔ عکس و انتشار: عکس را می‌توانی از حافظهٔ کامپیوتر یا موبایل انتخاب کنی؛ عکس انتخابی تا ۴ مگابایت داخل دادهٔ منو ذخیره می‌شود. برای تعداد زیادی عکس، بهتر است عکس‌ها را در پوشهٔ images پروژه نگه داری و مسیر محلی بدهی. نکتهٔ انتشار: این پنل یک ابزار جداگانه است و به سایت عمومی وصل نیست. تغییرات اینجا تا وقتی فایل خروجی را در پروژهٔ سایت جایگزین و روی GitHub منتشر نکنی، برای مشتری‌ها نمایش داده نمی‌شود. این نسخه ورود امن و همگام‌سازی ابری ندارد؛ فایل را فقط در اختیار مدیر نگه دار.
